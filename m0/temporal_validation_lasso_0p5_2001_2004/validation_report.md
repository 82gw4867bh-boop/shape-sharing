# 正式 M0 参考基线 v2：2001–2004 伤年时间评价

基线从既有五份训练集 MICE 插补中，按 1995–2000 内部验证四域等权平均 RMSE 选择第 3 份；MICE 没有重拟合。原五份仍用于训练组 Lasso α=0.5 筛选，最终四域各只对选定一份拟合一个随机截距 M0。第 3 份的内部验证四域 RMSE 分别为 28.073、23.342、33.504、22.711；四域平均 26.907。内部验证被用于选份，这些数值不应当作未经选择的验证性能。

时间组为 2,610 名伤年 2001–2004 的成人患者，按患者与开发组分离，使用伤后 1、5、10、15 年节点。训练集拟合的 MICE 插补器用相同的第 3 份随机种子变换该组 Form I；M0 只用训练集估计的固定效应预测，不使用时间组结局拟合参数、插补器或个人随机效应。CHART 误差只与真实有效结果比较；死亡后及死亡同年时序不明者不纳入评价。20 年节点未打开。
