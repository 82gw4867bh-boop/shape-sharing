# 出院 Form I 变量资格、预测性筛选与 M2 关系映射方案

## 1. 本方案解决什么问题

本文件规定：从 Form I 原始字段中建立合格候选池；在开发训练患者中用机器学习方法选出四个 CHART 领域各自的入模变量；提前记录预测变量之间的 `PredictorDomain`、`Family`、`Construct` 和可核对关系，供 M2 寻找待检验的共享基线函数，也供后续复杂互作扩展使用。变量筛选应在正式 M0 之前完成。数据清洗、缺失审计、插补、模型拟合和验证有各自的实施方案；本文件只规定它们与筛选的接口和先后顺序。

预测时点为初期康复出院。预测变量只能来自当时及此前可获得的 Form I 信息。四个结局分别为身体独立、移动、职业、社会融入的 CHART 分数，分别选变量、建模和报告；不构造四域总分。CHART 衡量社区参与，不是神经功能恢复。本研究是观察性预后分析，不推断干预因果效果。

### 三个容易混淆的概念

| 名称 | 含义 | 本方案中的用途 |
|---|---|---|
| CHART 领域 | 四个待预测的结局 | 四个预测任务；M0 分别拟合，M1 才检验跨领域时间共享 |
| 预测变量类别 | Form I 变量的 `PredictorDomain`、`Family`、`Construct` | 变量字典中的预先记录；M0/M1 不据此加入类别效应 |
| 变量关系等级 | 两个预测变量是重复、可转换、测量相近构念，还是仅临床相关 | M2 产生待比较的共享函数候选；等级本身不是共享证据 |

这里的“变量归类”是给**预测变量**建映射，不是给患者分神经亚组，也不是在 M0 加 `domain` 固定效应。当前主分析不按 `ANCatDis` 等神经分型筛人或预定义亚组。

## 2. 从数据到 M0 的顺序

1. 明确成人伤年队列和出院预测时点，在唯一 Form I 患者表上按 `UniID` 固定划分训练、内部验证和时间留出患者。一个人的所有访视和四域都留在同一组。
2. 依据数据字典及开发数据，核查字段的采集时间、特殊码、历史版本、跨年代可比性和缺失情况；形成**第一阶段合格候选池**。数值或类别的确定性清洗规则须写明。不能靠后来年份独有的字段直接填满早期年代。
3. 为候选池建立变量字典及有依据的关系表，并在看到 M2 函数结果之前冻结。归类可以提前完成，但 M0/M1 拟合时不使用 `Family` 或 `Construct` 作为模型效应。
4. 仅在开发**训练患者**中确定缺失预测变量的处理规则，拟合需要从数据学习的插补和标准化参数；在患者级训练折内重复这些步骤，完成**第二阶段预测性筛选**。内部验证、20 年结局和时间测试不参加筛选或预处理参数拟合。
5. 冻结每个 CHART 领域的原始输入变量清单及预处理规则，然后运行 M0。后续同一领域的 M1、M2 沿用这份清单；M1 改变时间共享结构，M2 在清单内探索简单函数和少量互作。若开展探索性 M3，也沿用已冻结的出院输入清单，并单独检验更复杂的互作及基线×时间关系。后续模型的最终表达式可只使用清单的一部分变量，但不临时引入清单外变量。

这是一项先筛选、再比较模型结构的主分析。若另要比较“重新选变量是否改善预测”，须列为单独分析，避免把输入变化误解释为 M1/M2 结构的收益。

## 3. 第一阶段：资格筛选（Eligibility Screening）

第一阶段回答“这个 Form I 字段有资格成为出院预测变量吗”，不根据它与任何 CHART 结局的单变量显著性决定去留。应记录下列判断：

- **时间有效性：**出院时或此前已知。Form II 的随访状态、失访原因、访谈条件、后续量表及 CHART 都不能作出院输入。死亡资料只用于界定和解释评价人群。`UniID` 用于连接、划分和随机效应；`AInjDt` 用于年代划分；`BYear` 是预测节点，不是 Form I 候选主效应。
- **定义与编码：**逐项核对取值、特殊码、结构性未采集、不同年代相同码是否含义相同。分类码不能盲目作为连续数值；例如出院神经水平和 AIS 有字符类别。
- **跨年代适用性：**区分真正缺失与当年未采集；记录字段启用/停用日期、版本变化和能够事先定义的 harmonization。只在后期采集的变量可考虑另设年代分析，不能不加说明放进本轮跨年代主比较。
- **数据质量：**按患者和伤年查看有效率、异常值、低方差、稀有类别及可解释的缺失机制。没有统一的机械缺失率阈值；保留或排除需附理由。出院输入的缺失应按患者计，不以四节点或四域完整为资格条件。
- **临床与重复性：**说明变量测量什么、是否适合出院时预后沟通。完全相同的信息或仅改变标签的重复编码保留一种；高度相关但信息不同的变量可以同留候选池，留待第二阶段处理。

当前流程从 2021 公开版 Form I 的全部 658 个原始字段开始。第一阶段逐项排除患者 ID、划分/连接字段、出院后不可得字段、开发年代严重或结构性缺失字段，以及缺乏可执行编码或跨年代对应规则的字段；其余保留字段全部进入共同候选池。既有可行性审计中的局部字段统计仅作为历史描述，不作为本流程的预选清单或候选数上限。

第一阶段的产物是 `candidate_variable_pool.csv` 及每个字段的最终保留或排除理由。审查中可暂记“待核查”；穷尽现有来源仍无法证实资格时，以具体证据缺口为理由排除，不把原始特殊码默默送入第二阶段。

## 4. 数据处理与缺失：位于两个筛选阶段之间，并嵌入第二阶段

先做特殊码识别、逻辑核验和版本 harmonization，再计算真实缺失。资格筛选需要缺失审计；预测性筛选则需要一个可以在新出院患者身上照样执行的处理流程。

- **Form I 预测变量缺失：**在开发训练患者中确定插补策略。若采用中位数、众数、缺失指示项或更复杂的方法，其估计值只从当前训练折学习；验证折只接受已学规则的转换。最终规则确定后，在完整训练患者中重拟合一次，再应用于内部验证和时间测试。插补器的输入限于出院时可用信息。
- **Form II 结局缺失：**主分析不统计填补 CHART；一个领域或节点缺失不删除其他领域或节点的真实有效分数。误差只与真实有效的 0–100 分数比较。死亡后 CHART 没有定义；死亡与节点同年先后不明须标记。
- **结构性年代缺失：**历史上根本未采集的字段不能靠常规插补变成跨年代共同变量；若采用跨版本转换，须有独立证据和冻结规则。
- **数值尺度：**若用 Elastic Net 等惩罚方法筛选，连续变量通常要在训练折内标准化，以免惩罚受单位影响；分类变量按类别编码。普通未惩罚混合效应 M0 本身不强制标准化，可用临床可读的单位。无论是否标准化，同一领域的 M0/M1/M2 应沿用已冻结的处理规则；CHART 仍以原始 0–100 分报告。

筛选与插补不能在划分患者前用全体数据一次完成。具体插补模型、缺失机制和敏感性分析属于独立数据方案；此处只规定无泄漏的执行位置。

## 5. 建立变量字典；预测性筛选后建立关系表

对每个合格候选变量建立一行字典，建议记录：原始字段、清洗后字段、含义、预测时点、类型、合法取值、特殊码、采集年代、缺失率、harmonization 规则、`PredictorDomain`、`Family`、`Construct`、派生来源和证据。`PredictorDomain` 指预测变量的信息领域，例如人口社会信息或神经检查；避免简称 `Domain` 与四个 CHART 结局混淆。

两种机器学习方法完成四域筛选并确定交接 M0 的清单后，对四域最终选入原始字段的并集，列出连续–连续与分类–分类的全部无序配对，逐对记录关系等级或“待核查”。不生成连续–分类配对；one-hot 展开列不视为待配对原始变量。关系表收录所有有依据的 L1–L4 配对。建议使用下列等级：

| 等级 | 关系 | M2 中的处理 |
|---|---|---|
| L1 | 同一信息的重复字段或确定性重复编码 | 资格阶段去重，保留映射记录 |
| L2 | 明确数学转换，或有证据支持且适用于本数据年代的已验证换算 | 核对公式、单位、适用范围后才转换到共同尺度 |
| L3 | 测量相近的临床构念，但不能直接数值互换 | 只提出函数形状比较候选 |
| L4 | 临床相关但构念不同 | 仅作探索线索；不能据标签合并系数或输入 |

`Family` 相同不等于 L2，也不等于互作机制相同。声称“已验证换算”时须给出适用人群、年代、方向和误差证据；若没有，就按 L3/L4 记录。完全重复与高度相关也不同：相关变量可并存，重复编码应在第一阶段去重。

关系表在第二阶段筛选后建立，并在查看 M2 的函数结果前冻结。新证据导致的修订须保留版本和原因，不能看完 M2 后临时把两个变量归为同类。关系表的创建**不强制**同一 `Family` 只选一个变量，也不要求四个 CHART 领域选出相同字段。

## 6. 第二阶段：训练患者中的预测性筛选（Predictive Screening）

四个 CHART 领域使用同一个合格候选池，但可分别得到 `S_physical`、`S_mobility`、`S_occupation`、`S_social` 四份入模变量清单。每份清单进入该领域的 M0，并在 M1/M2 的同领域比较中保持不变。若研究决定四域必须使用一个完全相同的输入集，须事先写明四域筛选结果如何合并及变量数上限；不能看验证结果后再取并集。

当前四域统一使用固定 `alpha=0.5` 的 Lasso 作为正式预测性筛选方法。此方法与强度是在查看开发阶段的 Lasso/Elastic Net 和不同惩罚强度结果后修订的，不能描述为事先预定。Lasso 的 `alpha=0.1、0.5、0.8、1、5` 既有审计及旧 Elastic Net 结果保留作历史比较；当前流程只计算 Lasso `0.5` 并交接 M0。若需要更严格地利用同一患者的重复测量结构，再评估纵向正则化或惩罚混合效应方法。惩罚回归的筛选结果是工作性候选，不是独立同分布推断或最终效应估计。当前不设原始字段数和展开列数上限；训练患者中仍执行 0.60 稳定性频率门槛、零方差及秩检查。

所有有结局参与的筛选、参数选择和重抽样都在训练患者内完成，重抽样按患者 ID 分组。在每一训练折内部重新拟合插补器、标准化器、编码规则中需估计的部分和筛选器；验证折只作转换与评价。内部验证可用于预先规定的开发判断，但不能反复使用到变成事实上的训练集；2001–2004 年时间留出与 20 年封存节点不用于选择变量、插补规则或复杂度。

对每个领域保存选入字段、类别展开后的列、筛选方法及参数、训练患者/行数、重复抽样选择频率与相关变量的替代情况。单次非零系数或单因素 `P<0.05` 不足以证明变量稳定。允许不同领域选中同一家族的不同代表，但不因为同属一个 `Family` 就自动合并或替换它们。

## 7. 冻结后怎样交给 M0、M1、M2

| 模型阶段 | 使用第二阶段结果 | 使用变量归类/关系表 |
|---|---|---|
| M0 | 四域分别拟合：各域的 `S_d` 以预定简单主效应进入，时间基准和患者随机截距另行规定 | 不生成 `Family` 或 `Construct` 效应；公式中没有 CHART `domain` 项 |
| M1 | 沿用各域的 `S_d` 和基线预处理，检验公共时间函数、完全共享与有限领域偏离 | 仍不根据预测变量类别宣称基线关系共享；从 M1 才出现模型的 CHART 领域结构 |
| M2 | 沿用各域的 `S_d`，在开发患者中探索简单基线函数和少量预定类型的互作 | 查询冻结的关系表，提出可比较的跨领域函数/互作候选，再检验独立、完全共享、部分共享结构 |
| 探索性 M3 | 沿用冻结输入，单独增加受限的三变量互作及出院基线变量×时间关系 | 继续使用已冻结的关系表提出候选，再检验新增结构是否有可重复收益 |

M2 的 SR 搜索应事先限定操作符、函数深度、变量数和互作数。三变量互作与一般的出院基线变量×时间互作具有研究价值；为辨别它们是否带来独立增益，本方案先将它们放在可选的探索性 M3，而不是称为不允许。若研究决定提前放入 M2，也应在开发患者中预先限定候选、复杂度和单独比较方案，并明确报告简单基线关系与新增复杂互作各自的贡献。四个主要节点不足以支持不受限制的时间函数搜索，20 年结局不能参与复杂度选择。

关系表可帮助识别“变量名不同但关系可能相近”的候选，例如两个领域分别出现 `年龄×变量 A` 与 `年龄×变量 B`；先核对 A/B 的定义、单位、可转换性及共同取值范围，再比较函数方向、形状、患者级验证和稳定性。`Family` 标签本身既不是数值转换，也不是共享结论。

比较 M0/M1/M2 时应保持患者划分、输入变量处理及逐域评价口径一致，并明确各域真正有分数的患者/节点分母。若复杂模型在未见患者上没有可靠的预测、校准或表达简洁性收益，保留较简单模型。时间测试是同一数据库内的年代验证，不是独立数据库外部验证。

## 8. 必须保存的决策与产物

建议在 `variable_screening/` 下保存以下版本化文件；名称可调整，但含义与追溯链应保留：

| 产物 | 至少记录什么 |
|---|---|
| `raw_variable_inventory.csv` | 原始 Form I 字段、来源、采集时间、原始类型 |
| `eligibility_rules.md`、`eligibility_screening_results.csv` | 资格规则、特殊码/年代核查、逐变量保留或排除理由 |
| `candidate_variable_pool.csv` | 冻结的合格候选池及版本 |
| `variable_dictionary.csv` | 清洗后名称、定义、类型、`PredictorDomain`、`Family`、`Construct`、来源与证据 |
| `variable_relation_table.csv` | 有依据的变量对、L1–L4 等级、换算条件或临床依据、版本 |
| `screening_config.yaml` | 划分 ID/种子、各域任务、预处理接口、筛选方法、患者级重抽样和复杂度规则 |
| `screening_method_results.csv`、`screening_method_comparison.csv` | 正式 Lasso `0.5` 的逐域字段频率、分类／连续及展开列数、训练患者交叉验证误差 |
| `selected_variables_by_domain.csv` | 四域的 `S_d`、选择频率、决策理由及冻结日期 |
| `screening_decision_log.md` | 特殊情况、定义冲突、修订理由与版本差异 |

现行 M0 正式入口只接受本流程输出的模型就绪数据与逐域变量清单，不读取原始 ZIP 或使用任何预设候选字段清单。M0/M1/M2 同领域比较沿用冻结的输入清单，并分别报告实际入模患者和结局行数。

## 9. 本方案的交付边界

本文件规定筛选与模型的交接，不把方案步骤写成已经完成的实证发现。具体插补模型、缺失机制审计、选择性应答/IPW、M1 联合相关结构、M2 SR 算法、校准及不确定性评价需要另行实现和验证。凡修改候选池、类别关系或变量处理规则，应在时间测试打开前记录修订并更新下游结果；时间测试表现不能用于回头选择变量。
